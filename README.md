> The legacy code you curse was written by a younger, braver you.

## How it works

`main.ts` (Node 22) writes the fortune line above, deterministically, to `/output/entry.txt`. The line is a single constant in the code — the same bytes on every run.

Run it:

```sh
node main.ts
```
